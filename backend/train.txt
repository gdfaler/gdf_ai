=== Python и PyTorch ===

PyTorch — библиотека для машинного обучения. Тензор — многомерный массив чисел. Модель описывается классом nn.Module. Оптимизатор AdamW обновляет веса по градиентам. Функция потерь cross_entropy сравнивает предсказание с правильным ответом.

import torch
import torch.nn as nn

class LinearModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer = nn.Linear(10, 1)

    def forward(self, x):
        return self.layer(x)

device = "cuda" if torch.cuda.is_available() else "cpu"
model = LinearModel().to(device)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

Для обучения: model.train(), loss.backward(), optimizer.step(). Для инференса: model.eval() и torch.no_grad().

=== Трансформеры ===

Трансформер состоит из блоков: нормализация, self-attention, feed-forward, residual connections. Self-attention вычисляет Query, Key, Value для каждого токена. Маска не даёт смотреть в будущее при обучении. RMSNorm стабилизирует активации. SiLU — функция активации в FFN.

Размер модели зависит от: vocab_size, dim (скрытый размер), layers (число блоков), block_size (контекст). Маленькая модель быстро обучается на CPU, большая требует GPU и много данных.

=== Короткие ответы на частые вопросы ===

В: Что такое токен?
О: Токен — единица текста для модели. Это может быть слово, часть слова или символ. SentencePiece разбивает текст на токены до vocab_size.

В: Зачем нужен tokenizer?
О: Модель работает с числами, а не буквами. Токенизатор переводит текст в последовательность id и обратно.

В: Что такое checkpoint?
О: Файл с сохранёнными весами модели. После обучения его загружают для генерации текста без повторного обучения.

В: Как ускорить обучение?
О: Используй GPU, mixed precision (autocast), больший batch size если хватает памяти, меньше данных для экспериментов, num_workers в DataLoader.

В: Что такое loss?
О: Число, показывающее ошибку модели. Чем меньше loss, тем точнее предсказания. Цель обучения — минимизировать loss.

=== Генерация текста ===

Модель предсказывает следующий токен по предыдущим. Берём logits последней позиции, выбираем argmax или sampling. Добавляем токен к контексту и повторяем. Temperature делает распределение острее или мягче. Top-k и top-p ограничивают выбор кандидатов.

При генерации важно ограничить block_size — модель видит только последние N токенов. Длинный промпт обрезается с начала или конца в зависимости от реализации.
